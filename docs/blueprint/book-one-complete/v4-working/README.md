## Provenance rule

Every v4 revision must preserve three distinctions:

1. **Inherited core:** prose carried from v3.
2. **Expansion:** new argument, evidence, qualification, or derivation attached
   to an inherited claim.
3. **Revision:** an intentional change to inherited wording, recorded with its
   scientific or editorial reason.

Expansion is preferred before revision. Existing language should change only
when additional research exposes an error, ambiguity, contradiction, or
unpayable argumentative burden.
