# Complete Book One — Claims Ledger

This ledger prevents a sentence from changing status as it moves through the
book. A claim can be revised, split, downgraded, or abandoned. It cannot become
an observation merely because later prose depends on it.

## Ledger rules

1. New core claims receive an ID before later chapters depend on them.
2. Splitting one claim into weaker claims is preferable to defending an
   overloaded sentence.
3. “Compatible with” is not evidence for a claim.
4. Evidence against a rival is not automatically evidence for DOT.
5. A metaphor never receives a hypothesis ID.
6. A prediction must name a possible result that counts against its parent
   hypothesis.
7. If no observation can discriminate a claim in principle, label the claim
   metaphysical and evaluate it by coherence, scope, and parsimony rather than
   calling it empirically confirmed.
